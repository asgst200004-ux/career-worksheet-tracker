# 진로활동지 스캔본 → 학생별 누적 엑셀 정리

## 개요

이 스킬은 진로전담교사가 스캔한 학생 활동지(주로 손글씨가 섞인 스캔 PDF)를 읽어서, **학생별로 시트 하나씩 있는 누적 엑셀 워크북**에 차시별 활동 내용을 정리해 넣는 작업을 표준화한 것이다. 한 번에 학생 한 명분이 올라올 수도 있고, 반 전체 학생의 같은 차시 활동지가 한 PDF에 이어붙어 올라올 수도 있다. 두 경우 모두 아래 절차를 따른다.

## 0. 먼저 확인할 것

- 이미 이 형식으로 만든 엑셀 파일이 대화 맥락(업로드된 파일, `/mnt/user-data/outputs`, 이전에 만든 파일 등)에 있는지 확인한다. 있으면 **그 파일을 이어서 사용**하고 새로 만들지 않는다.
- xlsx 관련 스타일링이 필요하므로 `/mnt/skills/public/xlsx/SKILL.md`도 함께 참고한다(이미 읽었다면 생략 가능).
- 반이 여러 개면(1반, 2반 …) **반마다 파일을 분리**한다. 파일명 예: `1학년_1반_진로활동정리.xlsx`, `1학년_2반_진로활동정리.xlsx`. 한 파일에 반을 섞지 않는다.
- 새 대화에서는 이전 대화의 파일을 볼 수 없다. 사용자가 "이어서"라고 했는데 그 반의 엑셀이 첨부되지 않았으면, 새로 만들기 전에 기존 파일을 올려 달라고 먼저 물어본다.

## 0-1. 차시 표기 규칙

- 정규 진로수업: `학기-차시` (예: `1-1`~`1-8`, 1학기 마무리 활동지는 `1학기 최종`, 2학기는 `2-1`, `2-2` …).
- **진로 프로젝트**(활동지 머리글이 "고등학교 1학년 진로연계 프로젝트"이거나 제목이 "N차시. 자료 수집 / 독서 전 활동 / 습관 기록표"처럼 트랙별로 다른 경우): `P-1`~`P-8`로 적는다. 사용자가 "2-3"처럼 다르게 불러도 **기존 파일에 이미 쓰인 표기(P-n)를 따르고**, 그렇게 붙였다고 사용자에게 한 줄로 알려준다.
- 진로 프로젝트는 학생마다 트랙이 달라 같은 차시라도 활동지 양식이 다르다. 활동명 칸에 트랙을 밝힌다. 예:
  - `진로 프로젝트 3차시(주제탐구): 자료 수집`
  - `진로 프로젝트 3차시(진로독서): 독서 전 활동 및 독서 활동 시작`
  - `진로 프로젝트 3차시(습관형성): 습관 실천 — 1주차 습관 기록표`
  응답 요약 첫 줄은 `[주제탐구] 자료 4개 수집`처럼 트랙과 분량을 먼저 적는다.
- 특이사항에는 **앞 차시와의 연결**(2차시 탐구 질문과 자료가 맞는지, 주제 변경, 짝과 주제 일치 여부, 자료 출처의 공신력 — 블로그·학원 자료만 있는지)을 짚는다.

## 1. PDF 읽기 (스캔본 처리)

1. `pdfinfo <파일>`로 페이지 수를 확인하고, `pdffonts <파일>`로 텍스트 레이어 유무를 확인한다.
   - 폰트 목록이 비어 있으면 텍스트 레이어가 없는 **스캔 이미지**이므로, 문서 전달 시 본문에 내용이 보이지 않는다. 이 경우 반드시 2번 단계로 이미지 변환 후 직접 읽어야 한다.
   - 텍스트/이미지가 대화의 `<document>` 블록으로 이미 제공되어 있으면 그 내용을 그대로 사용해도 된다(굳이 다시 렌더링할 필요 없음).
2. 스캔 이미지인 경우: `pdftoppm -jpeg -r 150 <파일> <출력폴더>/page` 로 전체 페이지를 이미지로 변환한 뒤, `view` 도구로 페이지를 하나씩 확인한다. 회전(예: `Page rot: 270`)이 걸려 있어도 `pdftoppm`이 보통 올바른 방향으로 렌더링해준다.
   - `pdfinfo`/`pdftoppm`이 없는 환경이면 `pip install pymupdf` 후 `pymupdf.open(파일)`로 페이지 수를 보고 `page.get_pixmap(dpi=110).save(...)`로 이미지화한다. 흘려 쓴 글씨는 dpi 220 정도로 다시 렌더링해 해당 부분만 잘라(PIL `crop`) 확대해서 읽는다.
3. 원본 활동지는 보통 **양면 스캔**이라 짝수 페이지(뒷면)가 앞면 글씨가 비쳐 보이는 거의 빈 페이지로 나온다. 이런 페이지는 무시한다.
4. 필체가 흐리거나 판독이 정말 어려우면 절대 지어내지 말고 "판독 어려움(원본 확인 필요)"이라고 정직하게 표기한다. 학생이 실제로 안 적은 항목은 "미기재"로 표기한다. 지나치게 개인적/민감한 내용(성적표, 가정사 서술 등)은 있는 그대로 요약하되 과장하거나 진단하지 않는다.

## 2. 문서 구조 판별 — "학생 1명" vs "반 전체 동일 차시"

- 페이지 수가 학생 1명의 여러 차시(보통 8차시 × 2페이지 = 16페이지, 일부 누락 시 더 적음)에 해당하면 **학생 1명 스캔본**이다.
- 페이지 수가 학급 인원수와 비슷하고, 각 페이지(또는 페이지 쌍)마다 학번·이름이 다르며 같은 차시 제목(예: "2-2 나도 입학사정관")이 반복되면 **반 전체 동일 차시 스캔본**이다. 이 경우 페이지마다 학번을 확인해 해당 학생 시트에 새 행 하나씩 추가한다.
- 학번이 기존 시트 목록에 없으면(결석 등으로 새로 추가되는 학생) 사용자에게 새 시트를 만들지 확인하거나, 명백히 같은 반 학생이면 바로 새 시트를 만든다.

## 3. 워크북/시트 구조

- 워크북 = 반 단위 파일 하나. 시트 = 학생 한 명(`"학번 이름"`, 예: `10101 정솔미`). 마지막에 `차시 목록(1-1~1-8)` 같은 반 전체 요약 시트를 하나 두고 항상 시트 목록의 맨 끝으로 이동시켜 둔다(`wb.move_sheet(...)`).
- 학생 시트 레이아웃(1행부터):
  1. 1행: 병합 제목(예: "2026학년도 1학년 진로수업 차시별 활동 정리 (학번 10101 정솔미)")
  2. 2행: 병합 안내 문구(판독 어려움/미기재 표기 원칙 설명, 이번 스캔본에 빠진 차시가 있으면 여기에 명시)
  3. 3행: 비움
  4. 4행: 헤더 — `차시 | 활동명 | 학습목표/개요 | 학생 응답 요약 | 특이사항 | 비고(미기재/확인필요)`
  5. 5행부터: 차시 하나당 한 행. **학기가 바뀌어도 별도 구분선이나 섹션 제목을 넣지 않고, 차시 열 값(예: "2-2")만 다르게 해서 바로 다음 행에 이어붙인다.** (사용자가 이 방식을 명시적으로 선호함 — 절대 "2학기 활동" 같은 별도 헤더 행을 삽입하지 말 것.)
- 스타일: 헤더는 진한 파란 배경(`4472C4`) + 흰 글씨 볼드, 본문은 연회색 얇은 테두리 + `wrap_text=True`. 열 너비 대략 `A:8, B:26, C:34, D:55, E:26, F:30`. 본문 행 높이는 넉넉히(120~160) 잡아 줄바꿈된 텍스트가 잘리지 않게 한다. `ws.freeze_panes = "A5"`로 헤더 고정.
- 재사용 가능한 헬퍼 함수가 `scripts/excel_helpers.py`에 있다. 새로 워크북/시트를 만들 때는 이 스크립트를 복사해 쓰거나 import해서 쓴다. 기존 워크북에 이어 붙일 때는 `openpyxl.load_workbook`으로 열고, 마지막 데이터 행(`ws.max_row`) 바로 다음 행에 `append_row`로 한 행만 추가한다 — 절대 별도 섹션 헤더를 새로 만들지 않는다.

## 4. 내용 요약 원칙 (응답 요약 칸)

- 학생의 답을 **자연스러운 한국어 서술**로 요약한다. 원문을 그대로 베끼기보다 핵심을 정리하되, 진로 관련 서술은 학생의 표현 뉘앙스를 살려 인용식으로 짧게 넣어도 좋다(예: "'꿈이 아직 정확하게 없다'고 솔직히 적음").
- 문항이 여러 개면 `\n`으로 줄바꿈해 항목별로 나열한다.
- "특이사항" 칸에는 다음과 같은, 교사가 상담 때 참고할 만한 패턴을 적극적으로 짚어준다:
  - 여러 차시에 걸친 진로 관심의 **일관성 또는 불일치**(예: 1차시엔 A라는 꿈, 5차시엔 전혀 다른 B를 선택)
  - 학생이 직접 밝힌 **불안감, 부모와의 의견 차이, 자신감 저하** 등 정서적 신호(진단하지 말고 사실만 서술)
  - 유난히 **완성도 높은/낮은** 차시, 특정 과목에만 편중된 학습계획 등
  - 활동 취지를 오해한 듯한 응답(예: 근거 대신 안내문구를 그대로 베낀 경우)
- "비고" 칸에는 미기재/판독 어려운 항목을 짧게 나열한다.
- 절대 의학적·심리적 진단명을 붙이지 않는다(아동/청소년 관련 민감 정보이므로 사실 기반 서술만 한다).

## 5. 차시 누락·부분 스캔 처리

- 특정 차시(예: 1-3, 1-4)가 이번 스캔본에 없으면 해당 차시 행에 "이번 스캔본에는 OO차시 활동지가 포함되어 있지 않아 정리할 내용이 없음"이라고 적어 행 자체는 만들어 두거나, 페이지가 아예 없으면 2행 안내 문구에 "이번 스캔본에는 1-3, 1-4차시가 포함되어 있지 않음"이라고 적고 표에서는 생략해도 된다(학생마다 상황이 다르면 뒤에 스캔본이 더 올 것을 가정해 두 방식 중 일관되게 하나를 쓴다).
- 한 학생의 스캔본이 1~2장뿐이면(예: 1-1, 1-5만) 2행 안내 문구에 이를 명시하고 해당 차시만 표에 채운다.

## 6. 반 전체 스캔본을 기존 시트들에 이어붙이는 절차 (구체 예시)

1. PDF를 페이지별 이미지로 변환하고 각 페이지에서 학번을 읽는다.
2. 학번 앞자리로 기존 시트를 찾는다(시트명이 `"10101 정솔미"` 형식이면 공백 앞부분이 학번).
3. 각 학생 페이지의 활동 내용을 요약해 `차시 | 활동명 | 개요 | 응답요약 | 특이사항 | 비고` 6개 값을 만든다.
4. 해당 시트를 열어 **`ws.max_row + 1`에 바로 그 값을 헤더와 같은 스타일로 한 행 추가**한다(구분 섹션 없이).
5. 모든 학생 처리 후 요약 시트를 다시 맨 끝으로 옮기고 저장한다.
6. 완료 후 사용자에게: 전체적으로 눈에 띄는 패턴(예: 다수 학생이 같은 항목을 비워둠, 특정 학생의 진로 일관성/불일치, 예상과 결과가 일치한 학생 등)을 짧게 브리핑한다.

## 6-1. 프로젝트 진행 확인표 탭 (진로 프로젝트가 있는 파일이면 항상)

진로 프로젝트(P-n) 행을 추가할 때마다 `프로젝트 진행 확인표` 시트를 함께 만들거나 갱신한다. 사용자가 따로 요청하지 않아도 한다.

- 구조(학생 1명 = 1줄): `학번 | 이름 | 트랙 | 주제/도서/습관 | P-1 제출·기록 | … | P-8 제출·기록 | 제출 차시 수 | '상' 차시 수 | 간단기록`
  - 제출: `○`(제출) / `×`(미제출). 빈칸으로 낸 활동지도 `○`로 하고 기록정도 `하`.
  - 기록정도 `상·중·하` 기준:
    - **상**: 모든 항목을 구체적으로 작성(주제탐구는 자료 3개 이상+요약, 습관형성은 요일별 기록이 대부분 채워짐)
    - **중**: 핵심 항목은 작성했으나 일부 빈칸·자료 1~2개·기록 일부
    - **하**: 대부분 빈칸이거나 출처·한 줄만 작성
  - 간단기록: `P-1 … → P-2 … → P-3 …`처럼 차시마다 한 구절씩 이어 붙인다(주제 변경, 보완 필요 사항 등 지도 포인트 위주).
  - 트랙은 P-1에서 고른 트랙(주제탐구/진로독서/습관형성), 주제 칸은 가장 최근 차시 기준 주제·도서명·습관 목표.
  - 제출 차시 수·'상' 차시 수는 COUNTIF 수식, 표 아래에 차시별 제출/미제출/상/중/하 인원 집계 수식.
  - 색(조건부 서식): 상 초록, 중 노랑, 하 주황, × 회색. 제출·기록 칸에 드롭다운(○,× / 상,중,하)을 걸어 교사가 직접 고칠 수 있게 한다.
  - 탭 색 초록, 시트 순서는 `학생 시트들 → 프로젝트 진행 확인표 → 요약 시트(맨 끝)`.
- 구현은 `scripts/excel_helpers.py`의 함수를 쓴다(직접 새로 짜지 않는다):
  ```python
  data = read_progress(wb)            # 기존 표 읽기(교사가 고친 값도 그대로 유지됨), 없으면 {}
  for 학생 in 이번_차시:
      update_progress(data, 학번, name=이름, sess_no=3, submitted="○", level="상",
                      note_add="P-3 자료 4개 충실히 요약", track="주제탐구", topic="…")
  update_progress(data, 미제출_학번, sess_no=3, submitted="×", note_add="P-3 미제출")
  write_progress_sheet(wb, data, "2026학년도 1학년 12반 진로 프로젝트 진행 확인표")
  ```
  - 파일이 `p-1`처럼 소문자 표기를 쓰면 `write_progress_sheet(..., label="p")`로 머리글을 맞추고 간단기록도 `p-`로 적는다. 요약 시트 이름이 `차시 목록`이 아니면 `summary_sheet_name=`에 실제 이름을 넘긴다.
  - 표가 아직 없는데 파일에 P-1, P-2 행이 이미 있으면, 학생 시트의 기존 P-n 행을 읽어 지난 차시 칸까지 먼저 채운다.
  - 이미 있는 칸의 상·중·하는 교사가 고친 값일 수 있으므로, 이번 차시 칸만 채우고 지난 차시 값은 바꾸지 않는다.
- 요약 시트는 반마다 모양이 다를 수 있다. **그 파일에 이미 있는 형식을 따른다.**
  - 학생×차시 `완료/일부/미작성/-` 현황표 형식이면: 마지막 프로젝트 차시 열 바로 뒤에 새 차시 열을 삽입(`insert_cols`)하고, 병합 범위(`A1:Q1` → `A1:R1` 등)와 열 너비를 한 칸씩 옮겨 다시 설정한다. 빈 행에는 값을 넣지 않는다. 아래 `차시별 활동 개요` 표에도 새 차시 줄을 추가한다. 짝과 내용이 같은 활동지·미제출 등은 메모 열에 한 줄 덧붙인다.
- 요약 시트(`차시 목록·반 현황`)에도 ① 차시 목록에 P-n 줄을 추가하고(바로 위 P-(n-1) 줄 스타일 복사), 맨 아래에 `⑤ P-n 진로 프로젝트 n차시 현황`처럼 번호를 이어서 차시별 현황 표(학번·이름·활동(트랙)·핵심 내용·작성 수준·확인 필요)를 추가한다.
- 활동지가 없는 학생은 그 학생 시트 2행 안내 문구 끝에 "P-n 활동지 묶음에도 이 학생의 활동지가 없었음(결석·미제출 확인 필요)."를 덧붙이고 행은 추가하지 않는다.
- 전달할 때 채팅에 차시별 제출·상/중/하 인원 표와 "세 번 연속 상/하, 미제출" 학생을 짧게 알려주고, 상·중·하는 1차 판단이니 드롭다운으로 고칠 수 있다고 안내한다.

## 7. 저장·전달

- 결과 파일은 `/mnt/user-data/outputs/`에 저장하고 `present_files`로 전달한다. 그런 폴더·도구가 없는 환경이면 사용자가 열 수 있는 작업 폴더에 저장하고, 그 환경의 파일 전달 도구로 보낸다.
- 같은 반 파일을 계속 갱신하는 경우, **같은 파일명을 유지**하며 덮어쓴다(버전 번호를 붙이지 않는다).
- 파일을 전달한 뒤에는 마크다운 후기(장문 설명)보다, 이번에 추가된 학생 수·눈에 띄는 특이사항 2~3개·현재 파일 구조(시트 목록)를 간단히 정리해 대화창에 알려준다.
