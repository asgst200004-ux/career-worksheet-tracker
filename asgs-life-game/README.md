# ASGS 고교 3년

고1 신입생이 되어 3년(24번의 달)을 보내고 진학이나 취업을 정해 졸업하는 진로 체험 게임입니다.

## 실행

- `index.html` 파일을 더블클릭하면 브라우저에서 바로 실행됩니다. 설치할 것이 없습니다.
- 게시된 페이지: https://claude.ai/artifact/8dbwExTPNhZ9HBcnWDcAjW
  (처음에는 비공개입니다. 학생에게 보내려면 페이지의 공유 메뉴에서 공개 범위를 바꿔야 합니다.)

## 게임 구성

- 시작: 네 가지 질문으로 성향(MBTI)을 고른 뒤 여학생 하린, 남학생 도윤 중 한 명을 선택 (이름은 바꿀 수 있음)
- 자기이해: 성향은 성적이 아니라 마음(덜 지치는 방식)에만 영향을 줌. 1학년 겨울방학 상담에서 직업 가치관 카드 8장 중 하나를 고르고, 게임에서 실제로 시간을 쓴 기록으로 흥미 순위를 보여 줌. 졸업 화면에 성향·흥미·가치관·강점을 모아 보여 줌
- 한 달 진행: 활동 카드 3장 선택 → 그달의 선택 문제 → 시험 결과 확인
- 학교 시험은 5등급제, 모의고사와 수능은 9등급제
- 1학년 동아리·2학년 선택과목, 2학년 탐구·3학년 선택과목·진학/취업 결정, 3학년 전형 선택·수시·수능 또는 직업교육 위탁과정·자격증·채용
- 작은 사건 21가지: 진로의 날 특강, 수학여행, 조별 과제, 부모님과의 진로 대화, 진로 심리검사, 독서토론, 아르바이트, 고3 슬럼프 등이 달마다 60% 확률로 생긴다(한 판에 10개 안팎, 같은 사건은 한 번만)
- 직업 카드 도감 36장(6개 분야 × 6): 진로 탐색·체험·독서 활동과 일부 사건에서 모으고, 하는 일과 관련 과목을 보여 준다
- 졸업 화면: 졸업 후의 길, 3년의 모습, 능력치 변화, 성적 흐름, 학생부 기록, 돌아보기 질문, 결과 요약 복사
- 그림: 인물(표정 4종: 기본·기쁨·지침·걱정)과 배경 장면(계절별 교문·교실, 운동장, 축제, 상담실, 밤 책상, 강당, 실습실)은 모두 코드로 그린 벡터 그림이라 별도 이미지 파일이 없습니다.

## 수정할 때

`index.html` 한 파일이 원본입니다. 게시 페이지를 갱신할 때는 이 파일에서
`<!doctype>`, `<html>`, `<head>`, `<body>` 태그와 charset·viewport 메타를 뺀 내용을 올립니다.

## 그림 파일

`img/` 폴더에 하린 그림 4장(`harin-*`)과 도윤 그림 4장(`doyun-*`)이 있습니다. 표정은 smile(기본), happy(기쁨), tired(지침), worry(걱정)입니다. `index.html`과 `img` 폴더를 같은 곳에 두어야 그림이 나옵니다.

배경 그림(`bg-*`): 교문 봄·여름·가을·겨울, 교실 봄·여름·가을·겨울, 강당(현수막 글자는 게임에서 올림), 실습실, 밤 책상, 진로 상담실, 운동장, 축제. 모든 장면이 그림 파일로 바뀌었습니다. 새 배경을 넣을 때는 `index.html`의 `SCENE_IMG` 목록에 추가합니다.

선택지 그림(`opt-*`): 분야 6장(hum, sci, med, biz, edu, art), 졸업 후의 길 3장(college, job, undecided), 입시 전형 3장(jonghap, gyogwa, jeongsi), 직업 가치관 8장(v0~v7). `index.html`의 `OPT_IMG` 목록에서 연결합니다.
